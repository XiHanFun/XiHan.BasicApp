# 更新日志

本页按总体方案的分期记录 `next` 分支上已经落地的内容，适用于跟踪 6.0 进度的读者。6.0 尚未发布，正式发布时整理为 `6.0.0` 的发布说明。5.x 的更新日志见 [5.x 文档](https://basicapp.docs.xihanfun.com/changelog)。

## 6.0.0-preview.1（未发布）

### 框架升锁 0eb19328（2026-11-04）

- 读入流程定义时即按模型的规则核对，模型不接受的值报出带路径的问题，不再等到运行时才失败；定义里没写的成员按模型的初值补上，与在设计器里新建的一致。
- 发件箱遇到消息代理抛出异常时，与代理返回失败一样计入重试、按退避重发，到上限进死信；一条消息出错不再拖住同批的其他消息。
- 框架代码的注释去掉了句末的「。」（与 BasicApp 同一写法）。

### 代码生成：第四批收尾（2026-11-03）

- 代码生成全部落地：单表、树表、主从三种模式生成的新包按登记片段登记之后，宿主 Release 构建没有警告，前端 `pnpm check` 八项通过。
- 新增手动触发的退出验证 `CodeGenerationCompileTests`（设 `XIHAN_TEST_CODEGEN_COMPILE` 为框架源码目录才跑），改了各包的写法要同时改模板并跑它。
- 业务名、表注释与列注释句末的「。」在生成的代码与页面文案里不再叠成「。。」（6.0 实体的注释句末都带「。」）；运行时数据与预览产物弹窗按 5.x 的宽度显示。

### 代码生成：零代码运行时（2026-11-03）

- 表配置多「运行时数据」：按表配置只读查看表里的数据，分页、每页最多 500 条，不生成代码，与 5.x 相同。
- 按表配置的数据源读（5.x 一律查主库）：主库的表只看调用方这一侧未删的行，外部库的表照原样读；数据行按列配置的属性名给键（5.x 按库里的列名给键，页面上取不到值）。
- 停用的表配置拒绝访问（`CODEGENERATION_CONFLICT_007`），库里读不出时报 `CODEGENERATION_UNAVAILABLE_003` 并带上原因。
- 权限码 `codegeneration.codegen-runtime.read`，只在平台一侧。

### 代码生成：生成与生成历史（2026-11-03）

- 表配置可以「生成并下载」或「生成到项目」（按表配置的交付方式二选一出现），代码生成页多「生成历史」页签：每次生成不论成败都记一条，详情带产物文件、用到的模板与失败原因，产物包在 7 天内可从历史下载。
- 产物包的结构与 5.x 相同（`_generated/`、`_manual/`、`README.txt`），另带登记片段；5.x 把产物包放进生成的响应，6.0 生成之后从历史下载（`GET /api/codegen-histories/{id}/package`）。
- 生成到项目只在开发环境且打开 `BasicApp:CodeGeneration:EnableGenerateToProject` 时可用，位置取配置的前后端根目录；只首次写的文件已存在即跳过，项目里有同名的手写文件即整体拒绝，与 5.x 相同。
- 权限码 `codegeneration.codegen-tables.execute`（生成）与 `codegeneration.codegen-histories.read`（生成历史与下载），只在平台一侧。

### 代码生成：前端模板（2026-11-03）

- 预览与生成多出前端页面：每张表一个 SchemaPage 列表页（新建 / 编辑弹窗、启停、删除、导入导出、打印，主表行展开看明细），页面结构只首次写，字段、按钮与表单换算每次随表结构重新生成；树表出树页，上级在同一棵树里选。生成目标是「新建包」时另出模块的启动钩子与 10 种区域的文案，「加入已有包」的文案写进登记片段。
- 与 5.x 不同：取数走生成的契约，不再生成接口与类型文件；文案一律按键写（5.x 是中文字面量）；日期按带时区的时刻收发；必填提示挂在字段上；枚举选项静态写出（6.0 没有枚举元数据接口）；选了枚举却解析不到的列在生成前就报错（5.x 出一个禁用的占位选项）；`long` 列是数字框（5.x 按数字字符串）。
- 5.x 的文件引用上传控件搬进公共组件，上传进文件库、字段存文件 ID；生成的列表查询可按创建时间区间筛选（与 5.x 相同）。

### 代码生成：模板与预览（2026-11-03）

- 代码生成页多「模板」页签：内置模板（随程序版本走，不能改、不能删，可以启停）与自有模板的增删改、正文在代码编辑器里写并可先检查语法，与 5.x 相同；表配置多「预览产物」：按目录树看生成的每个文件，标出只首次写的文件。
- 模板按 6.0 的写法重写：一张表生成一个资源的实体、请求与响应、按勾选的操作一份文件、列表查询的白名单，树表另有树、关联列另有选项操作、勾了打印另有打印数据源；生成目标是「新建包」时另出包级文件与 10 种区域的文案，两种目标都带一份登记片段，列出要合进解决方案、宿主或已有包的行。
- 与 5.x 不同：「是否启用」与状态合成一个启停，编辑时一起提交，模板列表里可以直接启停（内置模板也可以）；引擎只有 Scriban（5.x 的 T4 选了即报错）；生成前的检查不过、模板渲染出错时提示按界面语言，并带出错的模板编码；状态列要是有 `Active` 与 `Disabled` 的枚举（5.x 是全局的启停枚举），新建实体时没选枚举的整数列 `Status` 由生成器在实体里出 `<类>Status`。
- 权限码 `codegeneration.codegen-templates.{read,create,update,delete}`，只在平台一侧；预览要表配置的读权限。

### 代码生成：表结构导入、表与列配置（2026-11-03）

- 代码生成页多「表配置」页签：从主库或数据源导入库表（按表隔离，失败的列出原因）、编辑表配置（多「生成目标」：新建包或加入已有包，5.x 的父菜单不再需要）、列配置、同步表结构与删除，与 5.x 相同。
- 与 5.x 不同：导入时数据库类型按来源取，不再让人选；列类型按各库的类型名映射（Oracle 的 `NUMBER` 按精度分整数与定点数）；列配置里的列注释只显示（5.x 能改却不保存）；保存列配置不再把缺省值、正则与校验提示清空；选项与枚举的显示名按界面语言。
- 权限码 `codegeneration.codegen-tables.{update,delete,import}` 与 `codegeneration.codegen-table-columns.{read,update}`，只在平台一侧。

### 代码生成：数据源（2026-11-03）

- 新的可选模块 CodeGeneration（`BasicApp:Modules:CodeGeneration:Enabled`，缺省开，只在平台一侧）：代码生成页（`/codegeneration/code-gen`）先有「数据源」页签，表配置、模板、生成历史随后补上。见[代码生成](./backend/code-generation)。
- 外部数据源：新增、编辑、启停、删除与测试连接，与 5.x 相同；口令与连接串加密存储、不回显，编辑时留空即不改。与 5.x 不同：仍被表配置引用的数据源不能删除；测试连接要修改权限（5.x 只要查看权限）；编辑时连接串不再回填占位符（5.x 原样保存会把占位符存成连接串）；编辑弹窗里可以改状态。
- 权限码 `codegeneration.codegen-datasources.{read,create,update,delete}` 与页面读权限 `codegeneration.codegen-tables.read`，只在平台一侧。
- 6.0.0 基线多五张代码生成的表；已有的开发库重建即可。

### 授权与会话缓存的失效时机（2026-11-01）

- 授权类缓存（权限规则、角色指派、继承图、委托、条件、访问策略、字段安全、约束规则）的失效改到事务提交之后：新建角色委托不再要等一分钟缓存过期才生效，写入期间的并发请求也不会把旧数据写回缓存。见[缓存与异步](./backend/caching#缓存时长与失效)。
- 会话门禁与套餐门控同样改到提交之后失效：强制下线、改密、禁用、注销、锁屏与停止模仿时，恰在提交之前到达的同一会话请求不再把「有效」写回缓存，被吊销的会话不会在缓存过期前（缺省 30 秒）继续可用；换套餐与改白名单同理，租户的权限立即按新白名单计算。
