# 国际化与时区

本页说明管理端的区域、文案组织、文案门禁与时区处理，适用于前端开发者。

## 十种区域

前后端一致的 10 种内置区域：`en-US`（缺省与回退）、`zh-CN`、`zh-TW`、`ja-JP`、`ko-KR`、`de-DE`、`es-ES`、`fr-FR`、`pt-BR`、`ru-RU`。5.x 的 `hi-IN` 不保留。

## 文案位置

| 文案 | 位置 | 加载 |
| --- | --- | --- |
| 壳层 | `packages/locales/langs/<区域>.ts` | 按语言懒加载 |
| 各模块 | `src/modules/<包>/locales/<区域>.ts` | 模块的 `setup.ts` 调 `registerModuleLocales(import.meta.glob('./locales/*.ts'))` 登记，同样懒加载 |
| XiHan.UI 组件 | `packages/locales/xihan-ui.ts` | 随区域切换 |
| 菜单标题 | 后端页面登记的文案键（如 `identity.users.title`），前端模块文案里给译文 | — |
| 错误提示 | 后端按 `Accept-Language` 翻译好的 `detail`，前端直接展示 | — |
| 接口文档、权限显示名 | 后端消息目录（`permissionDefinitions` 已按区域生成） | — |

文件都是 `export default { … }` 的字面量对象：

```ts
// src/modules/settings/locales/zh-CN.ts
export default {
  settings: {
    configs: {
      title: '参数配置',
      actions: { create: '新建参数', override: '覆盖此参数' },
    },
  },
}
```

## 门禁

`pnpm i18n:check`：

- 10 个区域文件的键集完全对称（壳层与每个模块分别检查）；
- 源码里静态引用的 `t('…')` 键必须存在。

因此，枚举文案等动态键应写成静态的 `switch` 或映射，以便门禁核对：

```ts
function statusLabel(status: ConfigStatus): string {
  return status === 'Disabled' ? t('settings.configs.status.disabled') : t('settings.configs.status.active')
}
```

## 切换区域

切换区域会：懒加载该区域的壳层与模块文案 → 切 vue-i18n 与 XiHan.UI 的区域 → 之后的请求带新的 `Accept-Language`（错误文案随之换语言）。标签栏存的是文案键，切换后标题跟着变。

## 时区

后端一律存储 UTC 时间，返回带 `Z` 的 ISO 8601 字符串，不做服务端时区换算，也不再使用 `X-Timezone` 请求头。换算在客户端：时间按偏好设置里的**应用时区**显示（IANA 名，缺省 `Asia/Shanghai`），与浏览器所在的时区无关。

| 函数（`~/utils`） | 说明 |
| --- | --- |
| `formatDate(value, format?)` | 按应用时区格式化，页面上显示时间都用它；切换时区后已渲染的时间跟着重算 |
| `formatDateTime(value, timeZone, format?)` | 按指定时区格式化（dayjs utc + timezone） |
| `getDisplayTimeZone()` | 应用时区的当前值，按时区算「今天」的请求用它 |
| `utcOffsetMinutes(zone, at?)` | 某个时区在某一时刻相对 UTC 的分钟数（夏令时按那一刻算） |

只有日历日的串（`YYYY-MM-DD`）原样显示，不换算；空值、`NaN` 与解析不出的值显示 `-`。

时区切换器（`TimezoneSwitcher`，顶栏、悬浮工具栏与偏好设置）改的就是应用时区，随偏好设置跨端同步。个人中心的数据统计与工作台的「今日」「按小时」统计也按应用时区切天：前者请求带时区名，后者带时区偏移，由后端按本地日期计算。日期选择器收发的仍是浏览器本地时区的时间戳。
