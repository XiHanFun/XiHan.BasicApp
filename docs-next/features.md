# 功能清单

按 5.x 的功能分区逐项对照 6.0 的落地情况。状态说明：

- **已落地**：后端操作、权限、页面与前端模块都已提交到 `next`；
- **收尾中**：主体已落地，还在补 N2 收尾差距，括号里写明差什么；
- **规划中（N3 / N4）**：方案里有设计，代码尚未开始，现在**不可用**。

[功能预览](./preview) 说明如何在本地看到这些页面。
