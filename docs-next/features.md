# 功能清单

本页按 5.x 的功能分区逐项列出 6.0 的去处，适用于评估 6.0 的功能覆盖。[功能预览](./preview) 说明如何在本地看到这些页面，[更新日志](./changelog) 写明与 5.x 的行为差异。

## 工作台与身份权限

| 能力 | 6.0 去处 |
| --- | --- |
| 工作台 | Workbench + 各包 `IWorkbenchWidgetProvider`：公告轮播、今日统计与访问概况、在线设备、登录趋势、存储占用、作业执行等 10 个图表；看板布局经用户设置跨端同步 |
| 控制中心 | 前端 `_core/control-center`：可进入的租户与平台，`auth.switch-tenant` 切换 |
| 登录认证 | 密码、邮箱 / 手机验证码、第三方登录（GitHub、Gitee、Google、QQ、微信、企业微信、飞书、钉钉）、双因素（认证器 / 邮件 / 短信）、图形验证码、登录节流、账号锁定、登录失败自动封禁、锁屏 |
| 个人中心 | 资料与头像、改用户名、改密、手机邮箱验证与换绑、双因素、第三方绑定、登录设备、登录日志、通知偏好、我的租户、使用统计（含在线时长）、开放接口凭证、我的 OAuth 应用与授权 |
| 用户管理 | 高级搜索（手机号、性别、状态多选、创建时间、角色、部门）、启用停用、锁定解锁、重置密码、重置双因素、直接授权与 Deny、用户级数据范围、按人强制下线、模仿登录 |
| 在线用户 | 活跃会话（浏览器、系统、设备、登录地点、实时在线标记）、按会话吊销并推送下线 |
| 角色管理 | 角色 CRUD、授予 / Deny / 撤销（可带有效期与原因）、成员与指派有效期、上级角色（继承）、数据范围 |
| 组织机构 | 部门树（闭包表）、移动、负责人、部门成员（岗位、工号、职级、入职） |
| 岗位管理 | 岗位 CRUD 与启停 |
| 权限管理 | 权限目录页（只读）：权限由代码登记、从操作登记派生，不再能在页面上增删；条件盘点与试算 |
| 菜单管理 | 页面节点由各包登记生成、展示字段（含启停与徽标）可定制并可恢复；停用的节点不下发路由；运营可另建目录与外链；没有按钮节点 |
| 字段安全 | 各包登记可配置的实体与字段，按实体 × 字段 × 角色 / 用户 / 部门配置六种读取方式与只读 |
| 授权申请与委托 | 「授权申请」页：申请（提交即发起审批，通过即自动授予；撤回、修改重提、管理员手工驳回 / 撤回）与限时委托两个页签；工作流关掉时申请照常列出、不能提交 |
| 审批中心 | 待我审批、我已审批、我发起的、抄送我的；办理、转办、加签、撤回、审批轨迹；工作台「我的待办」 |
| 审批约束 | 约束规则 SSD / DSD / 互斥 / 基数 / 条件五类、四种违规处理；会话角色激活 |

## 6.0 明确删除的

Schema 隔离模式、扫码登录占位、网关灰度转发（需要时用 YARP）、服务端 `X-Timezone` 时区换算、第二套按钮码、前端数字字符串换算层、空的 `diagram` / `business` 目录、`hi-IN` 区域、5.x → 6.0 数据迁移工具。

还有这些 5.x 里有、6.0 没有搬的：

- 只有接口或前端门面、没有页面调用的接口：第三方绑定、历史密码、用户安全状态、用户统计、OAuth 授权码与令牌的查询；用户权限、用户角色、用户部门的单条详情；委托的修改与详情；枚举元数据的按名查询；租户成员的修改、改状态与详情；通知的用户通知查询；邮件短信的新增与修改；代码生成列配置的单条修改。
- 租户的简称、域名与 Logo（5.x 只用于显示和搜索，域名不参与租户解析）；成员邀请（5.x 也只有接口）；编辑器演示页。
- 配置 `XiHan:Upgrade:EnableFileUpdate`、`EnableRollingRestart`（升级只执行 SQL）与 `XiHan:VirtualFileSystem`；内建 OAuth 应用 `basicapp-web`（6.0 登录不经 OAuth 应用）。
