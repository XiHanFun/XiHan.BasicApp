曦寒基础应用能力包式中后台应用

后端基于 XiHan.Framework，前端基于 XiHan.UI；一份操作契约同时发布为 HTTP、gRPC 与 MCP，内置多租户与多层授权。

快速开始
应用简介
设计取舍

  • 能力包 + 操作契约

    每个业务能力是一个 IFeature，每个公开方法是一个 [Operation]；路由、OpenAPI、gRPC 方法与 MCP 工具都从同一份操作登记推导，不使用 Controller。

    了解架构

  • 多租户

    平台库实体不实现 IMultiTenant，租户库实体由框架仓储严格过滤并可随租户分库；租户 ID 是字符串，切换租户换令牌、整页重建。

    了解多租户

  • 多层授权

    授予来自框架 Security.Database，Deny、角色继承、限时委托、套餐门控与 ABAC 条件逐层收窄；数据范围与字段安全在查询与投影处显式套用。

    了解权限模型

  • 前端契约由后端生成

    后端导出一份 openapi.json，前端生成类型、操作客户端、权限码与枚举；CI 重新生成后比对，不一致即失败。

    了解契约层

  • RFC 9457 错误与无信封响应

    成功响应就是 DTO，失败是 application/problem+json；客户端只按 code 分支，字段级 errors 直接挂回表单。

    查看接口对接指南

  • 结构约束由测试保证

    包间层级、Expose 显式、权限码文法、匿名白名单、十种语言键集、XML 文档与框架版本锁定都由架构测试检查。

    了解开发流程

开始使用

按快速开始在本机建库，启动后端（启动时自动升级表结构）、写入种子，再启动前端。
