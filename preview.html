功能预览 ​

下面的截图与仓库 README 的「功能亮点」对应，逐项能力见功能清单；想直接上手可打开在线演示。


亮 / 暗双主题
每个页面、每个组件逐一对过色
一个色值生成整套配色
Material You 动态取色，21 个中国传统色预设

偏好中心
布局、配色、密度、快捷键与云端同步一处调好，另一台设备实时生效

Schema 驱动列表页
行悬停速览、高级搜索、列设置开箱即用
命令面板式全局搜索
Ctrl / ⌘ + K 呼出，拼音首字母直达页面与操作

应用内分屏
两个页面左右并排，互换不重载
多租户控制中心
平台管理与各租户之间一处切换

小屏适配
登录、仪表盘、抽屉菜单、命令面板与灵动岛，手机浏览器打开即可使用

工作台
小组件拖拽排布，看板布局云端保存
一个 TraceId 看全链路
七类日志串成时间线，桑基图看流向
