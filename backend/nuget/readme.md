## XiHan.BasicApp - 曦寒基础应用

基于 XiHan.Framework 和 XiHan.UI 的超高颜值通用中后台内核。

开箱即用，提供 RBAC + ABAC 混合权限管理、多租户隔离、代码生成、实时通信、灰度发布、AI等核心能力，满足新型企业级中后台管理场景。属于曦寒懿（XiHanFun）开源生态的基础应用。

此包为 [曦寒框架 XiHan Framework 和 曦寒界面 XiHan UI](https://docs.xihanfun.com) 的一种实现
