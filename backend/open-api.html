开放平台 ​

本页说明 OpenPlatform 包（Tier 2）提供的两种对外接入方式，适用于后端开发者与第三方对接方。

方式适合凭据
签名开放接口服务端到服务端，调用 open.* 操作个人中心申请的 AppKey / 密钥，HMAC 签名，可加密请求与响应
OAuth 2.0 / OIDC 服务端第三方应用以用户身份登录、取用户信息OAuth 应用的客户端 ID / 密钥，授权码 + PKCE

本页的「开放接口」与接口文档的 /openapi.json（OpenAPI 规范文档）不是一回事。

签名开放接口 ​

凭证 ​

开放接口凭证由 Identity 的个人中心自助管理（SysUserApiCredential，密钥加密存储），只要求登录：

操作说明
my-api-credentials.list / create / update / delete申请与维护凭证
my-api-credentials.rotate-secret轮换密钥
my-api-credentials.settings / update-settings签名算法（HmacSHA256 / HmacSHA512，缺省 HmacSHA256）与 IP 白名单，作用于本人全部凭证

凭证停用、或归属人账号不正常时验签一律失败；验签通过即记下凭证的最近使用时间。

验签中间件 ​

RequestSigningMiddleware 在 Authenticate 阶段、只对 open.* 操作生效，依次校验：请求头 → 时间窗（BasicApp:OpenPlatform:TimestampToleranceSeconds，缺省 300 秒，随机串保留它的两倍）→ 凭证 → IP 白名单 → 算法 → 请求体（超限 MaxRequestBodyBytes、解密）→ 内容签名 → 请求签名，最后才占用随机串防重放（伪造的请求不能把正常请求的随机串占掉）。签名用恒定时间比较；失败按类别给 400 / 403 / 409。

  • 签名恒开，没有「允许不签名」的开关；
  • 算法以凭证的设置为准，请求头只能与之一致；
  • 明文请求不必带 X-Encrypt-Algorithm: NONE；
  • 要求加密响应或请求本身加密时，成功的 JSON 响应换成信封 {alg, data, iv, contentSign}。

请求头、规范串与加密方式见接口对接指南。宿主在 UseXiHan() 之前经 UseOpenApiRequestBuffer 留下请求体原文，验签用原文、加密的先解密再重新绑定载荷。

开放操作 ​

操作说明
open.ping验签自检：返回 AppKey、归属人与服务端时间
open.echo回显（解密后的）请求，核对请求体、内容签名与加密

验签中间件只对 open.* 操作生效，需要开放给第三方的能力以 open.* 操作的形式新增。

开放接口日志 ​

每次 open.* 调用无论成败都登记一条开放接口日志（凭证、结果、耗时、请求响应摘要），由 Auditing 落库，open-api-logs.* 查询（auditing.open-api-logs.read），日志落在凭证归属人的注册地一侧。

OAuth 2.0 / OIDC 服务端 ​

端点 ​

前缀 /api/oauth2，宿主映射的普通端点，绕过内核管道，回原始 OAuth JSON（不是 Problem Details）：

端点说明
GET /api/oauth2/authorize把查询串原样带去前端同意页（BasicApp:OpenPlatform:ConsentPageUrl，缺省 /#/oauth/authorize）
POST /api/oauth2/token表单：authorization_code + PKCE、refresh_token；其他授权类型一律拒绝
POST /api/oauth2/revokeRFC 7009
GET / POST /api/oauth2/userinfo用户信息
GET /api/oauth2/.well-known/openid-configurationOIDC 发现文档
GET /api/oauth2/jwks签名公钥（SysOAuthSigningKey）

签发者取 BasicApp:OpenPlatform:Issuer，不配即请求来源加 /api/oauth2；反向代理后必须显式配置。ID 令牌有效期 IdTokenLifetimeSeconds（缺省 600 秒）。

同意 ​

前端同意页（packages/views/_core/oauth/authorize.vue）用当前登录的用户调用，全部只要求登录：

操作说明
oauth-consents.resolve解析授权请求，展示应用与请求的范围
oauth-consents.approve / deny同意或拒绝，同意即签发授权码并重定向
oauth-consents.list / revoke个人中心「已授权的应用」

应用管理 ​

操作权限码说明
oauth-apps.list / getopenplatform.oauth-apps.read平台管理全部应用（含用户自助注册的），客户端密钥不回显
oauth-apps.create / update / deleteopenplatform.oauth-apps.create / update / delete类型 Web / Mobile / Desktop / Service，客户端 Confidential / Public，回调地址、范围；删除后发给它的令牌即失效
oauth-apps.reset-secretopenplatform.oauth-apps.update重置客户端密钥
my-oauth-apps.list / get / create / update / reset-secret / delete登录即可个人中心「我的应用」：用户自助注册的应用

权限码只在平台一侧。作业 openplatform.oauth-cleanup 每天 03:30（UTC）物理删除过期一天的授权码与过期七天的令牌。

第三方登录 ​

用 GitHub、企业微信这类外部身份登录 BasicApp，是 Identity 的能力，见统一认证。
