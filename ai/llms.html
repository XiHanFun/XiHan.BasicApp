取本页 Markdown

LLMs.txt ​

本页说明文档站在构建时产出的机读资产及其用法，适用于为 AI 工具提供项目文档的开发者。机读资产与站点正文同源。

站点地址

本站部署在 basicapp.docs.xihanfun.com，构建产物里的绝对地址都写这个域名。没有部署的分支直接读仓库的 docs/ 源文件。

可用资源 ​

构建后在站点根目录下：

文件说明
llms.txt索引：全部页面的标题、一句话摘要与地址，以及下列资产的入口
llms-full.txt全站正文
llms-backend.txt后端手册：能力包、操作契约、认证授权、多租户、数据与平台能力
llms-frontend.txt前端手册：契约与请求、路由与菜单、权限、SchemaPage、主题、国际化与实时通信

单页 Markdown：任何一页的地址后加 .md 即可取到这一页的 Markdown（如 /api-guide.md）；每页正文上方的「取本页 Markdown」也指向它。开发服务器上按需生成。

在 AI 工具中使用 ​

text
阅读本站的 llms.txt 了解 XiHan.BasicApp；按需读取其中列出的页面（地址后加 .md 取 Markdown）。
以文档、仓库根的 AGENTS.md 与 backend / frontend 的代码为准。
工具做法
Claude Code写进仓库的 CLAUDE.md（它链接到 AGENTS.md）
Codex写进仓库的 AGENTS.md
Cursor写进 .cursor/rules，或在对话中添加文档
GitHub Copilot写进 .github/copilot-instructions.md
