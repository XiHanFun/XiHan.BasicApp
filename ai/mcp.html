MCP Server ​

本页说明宿主自带的 MCP 端点与开发时可用的 MCP 服务端，适用于把 BasicApp 接入 AI 客户端或用 AI 工具开发 BasicApp 的开发者。

宿主映射 /mcp：声明了 Expose.Mcp 的操作自动成为 MCP 工具，与 HTTP 接口共用同一份操作契约，认证、租户、权限与审计规则相同。编写代码时，还可以接入框架与 XiHan.UI 的 MCP 服务端查资料。

BasicApp 的 MCP 端点 ​

协议 ​

项说明
端点POST /mcp（开发时 http://localhost:9710/mcp，前端开发服务器也代理了 /mcp）
协议MCP 2025-06-18，JSON-RPC 2.0，Streamable HTTP；一条消息一个答复，不开 SSE、不建会话
认证请求头 Authorization: Bearer <访问令牌>，与 HTTP 接口同一个令牌；凭据无效即 401
区域Accept-Language 决定工具标题、说明与错误文案的语言
服务名XiHan:Protocols:Mcp:ServerName，缺省 XiHan.BasicApp

每个 tools/call 都是一次独立的内核调用：以令牌的主体与租户执行，经过权限判定、数据范围、字段安全与审计，和前端点按钮没有区别。

工具 ​

工具名由操作 ID 推导：<资源>_<动词>（资源段里的连字符保留，如 dict-items_list），可用 XiHan:Protocols:Mcp:Tools:<操作 ID> 覆盖。发布的都是只读操作：

工具操作权限
users_get / users_listusers.get / users.listidentity.users.read
departments_get / departments_treedepartments.get / departments.treeorganization.departments.read
positions_get / positions_listpositions.get / positions.listorganization.positions.read
memberships_listmemberships.listorganization.memberships.read
permissions_listpermissions.listaccess.permissions.read
dicts_get / dicts_list / dicts_optionsdicts.get / dicts.list / dicts.optionssettings.dicts.read / 登录即可
dict-items_list / dict-items_treedict-items.list / dict-items.treesettings.dict-items.read
tasks_listtasks.list（我的待办，受理人锁定为调用方）登录即可；Workflow 模块开着时
knowledge-documents_searchknowledge-documents.search（只在调用方一侧检索）ai.knowledge-documents.execute；AI 模块开着时
  • inputSchema / outputSchema 就是操作的请求 / 响应 Schema；
  • title / description 是操作的本地化文案；
  • 只读工具带 readOnlyHint；
  • 失败的调用返回 isError: true，文本是 错误码: 文案。

管理类写操作不发布到 MCP。新增 MCP 工具：操作必须只读（get / list 或声明 ReadOnly = true），在 Expose 里加 Expose.Mcp | Expose.Ai，并登记到架构测试 OperationExposureTests。

接入客户端 ​

以 Claude Code 为例，在项目根的 .mcp.json：

json
{
  "mcpServers": {
    "xihan-basicapp": {
      "type": "http",
      "url": "http://localhost:9710/mcp",
      "headers": { "Authorization": "Bearer <访问令牌>" }
    }
  }
}

访问令牌用 auth.login 取得（缺省 120 分钟有效）。令牌代表一个真实用户：给 AI 用的账号按最小权限授予，并留意工具调用同样进访问日志。

调试 ​

bash
curl -X POST http://localhost:9710/mcp \
  -H 'Authorization: Bearer <访问令牌>' -H 'Content-Type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'

开发用的 MCP 服务端 ​

服务端用途接入
xihan-framework（XiHan.Framework.Cli 的 mcp 命令）以 stdio 提供框架的离线知识库：包与特性清单、配置键与缺省值、文档检索见框架文档的 MCP Server；后端以源码引用锁定提交，对照时以同级检出的 framework/src 为准
xihan-ui（npm @xihan-ui/cli）组件 API、部件、示例与设计令牌见 XiHan.UI 的 MCP Server；版本取 frontend/pnpm-workspace.yaml catalog 里的 @xihan-ui/vue
