# 国际化与时区

本页说明前端的区域、文案组织、文案门禁与时区处理，适用于前端开发者。

## 十种区域

前后端一致的 10 种内置区域：`en-US`、`zh-CN`、`zh-TW`、`ja-JP`、`ko-KR`、`de-DE`、`es-ES`、`fr-FR`、`pt-BR`、`ru-RU`（`~/locales` 的 `LOCALES`）。

初始区域依次取本机保存的偏好、浏览器语言（`navigator.languages` 中第一个能匹配的）、`en-US`；缺键时回退到 `en-US`。

## 文案位置

| 文案 | 位置 | 加载 |
| --- | --- | --- |
| 壳层 | `packages/locales/langs/<区域>.ts` | 按区域懒加载 |
| 各模块 | `src/modules/<包>/locales/<区域>.ts` | 模块 `setup.ts` 调 `registerModuleLocales(import.meta.glob('./locales/*.ts'))` 登记，与壳层文案一起按区域懒加载 |
| XiHan.UI 组件 | 组件库自带的语言包，映射在 `packages/locales/xihan-ui.ts` | 随区域切换 |
| 菜单标题 | 后端页面登记的文案键（如 `identity.users.title`），译文写在模块文案里；运营在菜单管理里改过或新建的节点直接下发原文 | — |
| 错误提示 | 后端按 `Accept-Language` 翻译好的 `detail`，前端直接展示 | — |
| 权限显示名与说明 | 权限目录 `permissions.list` 按请求的 `Accept-Language` 返回；生成的 `permissionDefinitions` 只当权限码表用 | — |
| 枚举文案 | 前端按契约字面量写在模块文案里（`enums.ts` 只有成员与类型） | — |

文件都是 `export default { … }` 的字面量对象：

```ts
// src/modules/settings/locales/zh-CN.ts
export default {
  settings: {
    configs: {
      title: '参数配置',
      actions: { create: '新建参数', override: '覆盖此参数' },
    },
  },
}
```

vue-i18n 把 `@` 当链接语法，文案里不要写裸 `@`。

## 门禁

`pnpm i18n:check`：

- 壳层与每个模块的 10 个区域文件分别以 `en-US` 为准核对，键集完全对称；
- 源码里静态引用的 `t('…')` / `$t('…')` 键必须存在。

动态拼出来的键门禁看不到，枚举文案等应写成静态的 `switch` 或映射：

```ts
function statusLabel(status: ConfigStatus): string {
  return status === 'Disabled' ? t('settings.configs.status.disabled') : t('settings.configs.status.active')
}
```

## 切换区域

偏好里的区域是唯一入口：改了它就懒加载该区域的壳层与模块文案 → 切 vue-i18n 与 XiHan.UI 的区域、写 `<html lang>` → 之后的请求带新的 `Accept-Language`（错误文案随之换语言）。区域随偏好跨端同步。标签栏存的是文案键，切换后标题跟着变。

## 时区

后端存储并返回 UTC 时间（带 `Z` 或偏移的 ISO 8601 字符串），不做服务端时区换算，也不读时区请求头。换算在客户端：时间按偏好设置里的**应用时区**显示（IANA 名，缺省 `Asia/Shanghai`，设为空即跟随浏览器），与浏览器所在的时区无关。

| 函数（`~/utils`） | 说明 |
| --- | --- |
| `formatDate(value, format?)` | 按应用时区格式化，页面上显示时间都用它；切换时区后已渲染的时间跟着重算 |
| `formatDateTime(value, timeZone, format?)` | 按指定时区格式化（dayjs utc + timezone） |
| `getDisplayTimeZone()` | 应用时区的当前值，按时区算「今天」的请求用它 |
| `utcOffsetMinutes(zone, at?)` | 某个时区在某一时刻相对 UTC 的分钟数（夏令时按那一刻算） |

只有日历日的串（`YYYY-MM-DD`）原样显示，不换算；空值、`NaN` 与解析不出的值显示 `-`。缺省格式 `YYYY-MM-DD HH:mm:ss`。

时区切换器（`TimezoneSwitcher`，顶栏、悬浮工具栏与偏好设置）改的就是应用时区，随偏好跨端同步。按天统计也按应用时区切天：个人中心的活跃度、用户详情的统计请求带时区名（`timeZone`），工作台小组件带该时区的 UTC 偏移分钟。聊天里的「今天 / 昨天」同样按应用时区算。日期选择器收发的是浏览器本地时区的时间戳。
