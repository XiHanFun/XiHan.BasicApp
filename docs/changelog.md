本页记录各版本中使用者与运维可感知的变化，每条标注 **新增 / 修复 / 优化 / 调整** 类别，适用于评估与升级版本的读者；仓库自身的 CI、测试与构建脚本不列入。

## v6.0.0-preview.1 (2026-11-10)

::: warning 预览须知
- 这是预览版，正式版前接口、配置与表结构仍可能调整。
- 后端依赖 XiHan.Framework 5.0.0-preview.2（同级检出了框架时按 `backend/props/framework.props` 锁定的提交以源码构建，代码与这个包相同），前端依赖 XiHan.UI 5.5.1。
- 新部署要新建库：启动宿主（或先执行 `schema upgrade`）建表并写版本台账，再执行一次 `seed`。
- **首次执行 `seed` 必须配 `BasicApp:Seed:SuperAdminPassword`**，没有公开的缺省密码（`appsettings.Development.json` 里的值只用于开发）。
- 非 Development 环境必须提供 `XiHan:Security:Jwt:Secret` 与 `XiHan:ObjectStorage:SignedUrls:Secret`（UTF-8 至少 32 字节），缺失或太短启动即失败。
:::

### 架构与协议

- **新增** 能力包：每个业务能力是一个 `IFeature`，分四层、只能向下依赖，由架构测试守护；可选模块（工作台、工作流、打印、代码生成、聊天、AI）用 `BasicApp:Modules:<名>:Enabled` 开关，缺省都开
- **新增** 操作契约：每个公开方法是一个 `[Operation("<资源>.<动词>")]`，路由、OpenAPI、gRPC 方法与 MCP 工具从同一份登记推导；每个操作显式声明暴露面，超出 HTTP 的逐个登记且必须只读，只读查询走 GET
- **新增** 成功响应就是 DTO，失败是 RFC 9457 `application/problem+json`，字段级错误放 `errors`（见[接口对接指南](./api-guide)）
- **新增** 前端的类型、操作客户端、权限码、枚举与推送方法由后端导出的 `openapi.json`、`realtime.json` 生成，CI 重新生成后比对
- **新增** 文案与代码分离：每个包 10 种区域的消息目录，错误只带键与参数，由宿主按 `Accept-Language` 翻译；平台库 `message_translation` 可以按区域覆盖
- **新增** 接口文档的标题、标签、分组与字段说明本地化，`/openapi/<组>.json` 按包分组
- **新增** MCP 端点 `/mcp`：用户、部门、岗位、部门成员、权限、字典、知识检索与我的待办等只读目录类操作发布为 MCP 工具（见 [MCP Server](./ai/mcp)）
- **新增** 网络调用方的租户只来自令牌：HTTP、gRPC、MCP 入站丢掉调用方写的 `xihan.tenant`、`xihan.principal`，进租户走 `auth.switch-tenant`

### 账号与认证

- **新增** 登录：密码、邮箱 / 手机验证码、第三方登录（GitHub、Gitee、Google、QQ、微信、企业微信、飞书、钉钉）、双因素（认证器、邮件、短信）、图形验证码、登录节流、账号锁定、自助注册（缺省关）与找回密码
- **新增** 注册要先勾选同意隐私政策与服务条款；两份文书按 10 种界面语言放在前端 `packages/views/_core/authentication/legal/`，**部署前按自己的主体、联系方式与条款改写**
- **新增** 令牌与会话：HS256 访问令牌加不透明刷新令牌，每次刷新轮换；会话门禁、锁屏、按人或按会话强制下线；切换租户换令牌、整页重建
- **新增** 每个账号可以限制同时登录：不允许多端或限定设备数
- **新增** 个人中心：资料、裁剪后上传头像（圆形取景、存正方形）、改用户名、改密、联系方式验证与换绑、双因素、第三方绑定、登录设备与日志、使用统计；可以停用或注销本人账号（要当前密码，模仿会话不能做，租户所有者要先转移所有权）
- **新增** 系统内置账号（初始超级管理员、租户开通时的管理员）不能被停用、删除、锁定或由管理员重置密码，本人也不能改用户名或关闭账号
- **新增** 强制改密（系统参数 `identity.password` 的 `forceChange`，缺省关）：打开后，密码由他人设置的账号凭密码登录要先改密
- **新增** 模仿登录：缺省 30 分钟并通知被模仿者（系统参数 `identity.impersonation`，最多 480 分钟），时长是硬期限，能刷新但不能续期；一条原会话同时只挂一条模仿会话；不能选超级管理员或同级、更高权限的账号；模仿态拒绝接管账号、变更授权、销毁数据、重置 OAuth 客户端密钥与处理授权申请
- **新增** 用户管理：真实姓名、性别、生日、国家与备注；列表带头像、地区、角色、部门与安全标记，详情看验证状态、双因素、今日统计与当前会话
- **新增** 密码哈希 PBKDF2-SHA256，迭代 60 万次

### 权限与访问控制

- **新增** 授予来自框架 `Security.Database`；Deny、授予与指派的有效期、用户直授、角色继承、限时委托、套餐门控与 ABAC 条件逐层收窄
- **新增** 权限目录由代码登记、从操作登记派生，页面只读，权限名按界面语言显示；启停并入修改权限，角色的收回权限、移出成员、解除上级并入授予的那一个码
- **新增** 数据范围（角色与用户级）在查询里显式套用；字段安全按实体、字段与角色 / 用户 / 部门配置六种读取方式，在投影时套用
- **新增** 访问策略：平台与租户两层、三个时机、六个模板，能试运行并记命中，有防自锁；只管外部协议（HTTP、gRPC、MCP），不管作业、消息处理与工作流；登录失败自动封禁
- **新增** 约束规则五类（SSD、DSD、权限互斥、基数、条件）与会话角色激活
- **新增** 授权申请：为自己申请角色或权限，提交即发起审批，通过即自动授予；工作流关掉时照常列出、不能提交
- **新增** 作用侧在运行时判：租户主体持 `*` 也调不到只属于平台的操作，反过来同样
- **新增** 代他人委托时，操作者自己也要持有所委托的权限或角色；改别人的邮箱或手机号要有重置密码的权限，系统账号的联系方式只有本人能改，也不能被重置双因素
- **新增** 菜单：页面节点由各包登记生成、只调展示，没有按钮节点；运营可另建目录与外链

### 组织与租户

- **新增** 部门（闭包表）、岗位、部门成员；部门支持关键字搜索，带类型与联系方式，归属带备注
- **新增** 租户开通三步（创建、可选初始化独立库、初始化管理员）、停用恢复、换套餐、配额、到期生效、所有权转移、运维支持成员
- **新增** 租户的用户列表带出在别处注册、生效中的本租户成员（外部成员），能配本租户的角色、部门、数据范围与直授，账号本身只有注册地与平台能动；运维支持成员只读、能配角色，最近登录时间与 IP 不下发给租户，不占席位，不进模仿候选、群发收件人和聊天目录
- **新增** 套餐：价格、计费周期、配额、权限白名单、启停；停用的套餐不能再分配，已绑定的不受影响，缺省套餐必须启用
- **新增** 平台数据不实现 `IMultiTenant`，平台与租户两侧严格分开；租户库实体可随租户分库

### 消息与协作

- **新增** 通知公告：定向投递、横幅与弹窗、强制阅读、提醒、阅读统计；正文用 Markdown 编辑器，HTML 渲染前净化
- **新增** 收件箱、消息模板（邮件、短信、站内通知、机器人，Scriban 变量，租户覆盖平台模板）、邮件短信发送记录、多通道配置、群机器人（钉钉、飞书、企业微信）、Telegram 机器人
- **新增** 在线聊天：单聊、群聊、部门群（随部门归属自动进出）、助手会话；撤回、编辑、表情回应、置顶、提及、已读回执、正在输入；转发由服务端一次完成，附件以会话为访问范围；聊天审计、敏感词与保留清理（系统参数 `chat.policy`）
- **新增** 实时推送：通知 Hub 与聊天 Hub；配了 Redis 时跨实例，配了 RabbitMQ 时强制下线还由所在实例断开；导出任务与通知发布的进度推到灵动岛
- **新增** 群机器人的 Webhook 地址加密存放，响应只给主机；解不开时不当明文用，发送失败并在发送记录里写明原因
- **新增** 验证码的发送记录不留正文、不能重发；发送记录、导出任务与助手回复的失败原因只记异常类型，完整异常看应用日志；机器人返回错误时只记状态码

### 文件与导出

- **新增** 上传、秒传、分片上传、签名下载与预览（支持 Range）、元数据、归档、副本与主存储、校验
- **新增** 存储配置支持本地与 S3 兼容服务；不认 `If-None-Match` 的服务可以按条关掉条件写入
- **新增** 导出中心以发起人的身份逐页调列表操作，CSV / XLSX 存 7 天，到期的临时文件由作业 `files.temporary.purge` 清理；CSV 导出防公式注入
- **新增** 响应一律带 `X-Content-Type-Options: nosniff`；文件只有图片（不含 SVG）、音视频、PDF 与纯文本能内联打开，别的类型以附件下载；`/blobs` 除 PDF 外放进沙箱

### 日志与审计

- **新增** 八类日志与按 trace-id 聚合的链路追踪；分表日志经有界队列批量写入，保留清理作业
- **新增** 操作日志的描述取操作的本地化标题；数据变更日志区分「恢复」，遮加密参数的值、AI 密钥、连接串与 Webhook 地址
- **新增** 访问日志与开放接口日志可以按耗时上下限筛选，异常日志可以按发生位置筛选

### 系统管理

- **新增** 参数（平台加租户覆盖、加密值不回显，关掉加密且不给新值时清空）、字典（树形项）、业务编号、用户设置（跨端同步）
- **新增** 任务调度：代码登记与运行时作业、Cron 构建器与固定间隔、暂停恢复、立即执行、改计划与恢复、失败重试与单次执行时限、运行历史
- **新增** 缓存管理按命名空间列键、查看、修改、删除；服务监控；版本台账与升级记录
- **新增** 表结构升级器：`Schema/<版本>/` 脚本加台账，平台库之后逐个升级已就绪的独立库，升级期间别的节点进入维护模式（503）
- **新增** 开放平台：签名开放接口与自助凭证、OAuth 2.0 / OIDC 服务端、OAuth 应用、我的应用、授权同意；CloudEvents 入站端点（缺省关，要 `runtime.cloud-events.deliver`，这个权限只在平台一侧）

### 工作流与审批

- **新增** 框架的数据库工作流，流程数据按平台与租户分区落表，随业务事务提交或回滚；全屏设计器、发布、版本、挂起恢复、取消终止、重试
- **新增** 受理人可按指定用户、发起人、表达式、角色、部门、部门负责人、岗位、发起人第 N 级主管与主管链配置
- **新增** 审批中心：待我审批、我已审批、我发起的、抄送我的；办理、转办、加签、撤回、审批轨迹；业务包可经审批业务接入
- **新增** 流程故障的原因按看的人的语言显示；活动抛异常或 `Http` 活动连不上时，原因只有异常类型，完整异常看应用日志

### 代码生成与打印

- **新增** 代码生成：数据源、表结构导入、表与列配置、模板维护与预览（Scriban）、生成与生成历史、零代码只读运行时；单表、树表、主从三种模式生成的新包能编译、能过前端门禁，前端取数走生成的契约；产物包从生成历史下载；数据源换数据库类型时，端口跟着换成该库的缺省端口
- **新增** 生成到项目只在开发环境且打开 `BasicApp:CodeGeneration:EnableGenerateToProject` 时可用；表名不能改；零代码运行时不读应用自己的表；外部数据源过出站地址策略；SQLite 数据源缺省关（`BasicApp:CodeGeneration:AllowSqliteDataSource`）
- **新增** 打印模板：平台全局与租户模板、按编码解析、数据源经 `AddPrintDataSource` 登记，拖拽设计、样例数据、预览与直打

### AI

- **新增** AI 提供商（OpenAI 兼容，密钥加密，设缺省，测试连接；厂商不是 OpenAI 时端点必填）、提示词、知识库、助手

- **新增** 平台与各租户各自维护知识，互不可见；检索失败即回复失败，不退化成纯模型回答；还被引用的提示词与提供商不能删除；最大输出与温度生效

- **新增** 偏好、收藏与页面设置（列设置、搜索设置、个人视图、看板布局）跨端同步，同一账号在别的设备上改了，已打开的页面实时生效

- **新增** 工作台：各包登记的指标、图表与列表小组件，看板布局跨端同步，「我的待办」
- **新增** 关于页与内置的「帮助中心」目录（种子只首写，之后可改、可停用、可删）；时区目录用浏览器 `Intl`

### 配置与运维

- **新增** 配了 Redis（绑定 `cache`）即装分布式缓存，配了 RabbitMQ（绑定 `queue`）即装消息代理，不配仍是单机零外部依赖；配了连不上启动即失败
- **新增** 出站地址策略：向用户填的地址发请求时，缺省只能连公网地址（`XiHan:Security:Outbound`）。工作流 `Http` 活动、群机器人 Webhook、SMTP 服务器、AI 提供商、第三方登录、S3 兼容存储与代码生成的外部数据源都受约束。**自建 MinIO、内网 Webhook、内网 SMTP 中继、内网业务库、流程调内网服务、本机模型端点要在这一节放行**；Telegram 的 `Network.BaseUrl` 改成自建地址时，主机要在 `AllowedHosts` 放行
- **新增** 平台库可以配从库（`BasicApp:Database:Replicas`），从库健康探测缺省开；授予、租户目录与决定授权的读取都读主库（见[部署](./deployment#读写分离)）
- **新增** SQL 日志、错误日志与慢 SQL 可配；SignalR 的保活、超时与消息大小可配；转发头（缺省只信本机回环）与跨域（不配即不启用）可配
- **新增** 数据库宕了，`persistence.sqlsugar.database` 与运行时数据源的健康项如实报失败（`KERNEL_UNAVAILABLE_005`）；代码生成的数据源连接测试有上限，缺省 15 秒（`XiHan:Persistence:DataSources:HealthProbeIntervalSeconds`）
- **新增** `docker-compose.yml` 一键起 PostgreSQL、后端与前端，`init` 服务先执行表结构升级与种子（见[部署](./deployment#容器-docker-compose)）
