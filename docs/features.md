# 功能清单

本页按功能分区列出现有功能，适用于评估功能覆盖。[功能预览](./preview)说明如何在本机看到这些页面。

## 工作台与身份权限

| 能力 | 说明 |
| --- | --- |
| 工作台 | 各包经 `IWorkbenchWidgetProvider` 登记的指标、图表与列表：公告轮播、今日统计与访问概况、在线设备、登录趋势、存储占用、作业执行、我的待办等；看板布局经用户设置跨端同步 |
| 控制中心 | 可进入的租户与平台，经 `auth.switch-tenant` 切换 |
| 登录认证 | 密码、邮箱 / 手机验证码、通行密钥、第三方登录（GitHub、Gitee、Google、QQ、微信、企业微信、飞书、钉钉）、双因素（认证器 / 邮件 / 短信）、图形验证码、登录节流、账号锁定、登录失败自动封禁、锁屏、自助注册（缺省关）与找回密码 |
| 个人中心 | 资料与头像（裁剪后上传）、改用户名、改密、手机邮箱验证与换绑、双因素、第三方绑定、登录设备、登录日志、通知偏好、我的租户、使用统计（含在线时长）、开放接口凭证、我的 OAuth 应用与授权、停用或注销本人账号 |
| 用户管理 | 高级搜索（手机号、性别、状态多选、创建时间、角色、部门）、CSV 批量导入（共用初始密码，可一并入部门、配角色）、启用停用、锁定解锁、重置密码、重置双因素、直接授权与 Deny、用户级数据范围、按人强制下线、模仿登录、同时登录限制 |
| 在线用户 | 活跃会话（浏览器、系统、设备、登录地点、实时在线标记）、按会话吊销并推送下线 |
| 角色管理 | 角色 CRUD、授予 / Deny / 撤销（可带有效期与原因）、成员与指派有效期、上级角色（继承）、数据范围 |
| 组织机构 | 部门树（闭包表）、移动、负责人、类型与联系方式、部门成员（岗位、工号、职级、入职） |
| 岗位管理 | 岗位 CRUD 与启停 |
| 权限管理 | 权限目录页（只读）：权限由代码登记、从操作登记派生，名称按界面语言显示；条件盘点与试算 |
| 菜单管理 | 页面节点由各包登记生成，展示字段（含启停与徽标）可定制并可恢复；停用的节点不下发路由；运营可另建目录（可多级嵌套）与外链；没有按钮节点 |
| 字段安全 | 各包登记可配置的实体与字段，按实体 × 字段 × 角色 / 用户 / 部门配置六种读取方式与只读 |
| 授权申请与委托 | 「授权申请」页：申请（提交即发起审批，通过即自动授予；撤回、修改重提、管理员手工驳回 / 撤回）与限时委托两个页签；工作流关掉时申请照常列出、不能提交 |
| 审批中心 | 待我审批、我已审批、我发起的、抄送我的；办理、转办、加签、撤回、审批轨迹 |
| 约束规则 | SSD、DSD、权限互斥、基数、条件五类；违规处理有拒绝、警告、记录与需要审批四种（需要审批时，给用户指派角色与直授权限转为授权申请，审批通过后生效）；会话角色激活 |
| 访问策略 | 平台 / 租户两层、认证前 / 认证后 / 登录三个时机、六个模板、试运行与命中记录、防自锁；只管外部协议（HTTP、gRPC、MCP） |

## 租户与消息协作

| 能力 | 说明 |
| --- | --- |
| 租户管理 | 开通三步（创建、可选初始化独立库、初始化管理员）、停用恢复、换套餐、配额、到期生效、成员与运维支持成员、所有权转移 |
| 版本套餐 | 价格、计费周期、用户与存储配额、权限白名单（套餐门控）、启停；种子写入免费版（缺省）/ 基础版 / 专业版 / 企业版 |
| 我的订阅 | 当前套餐、期限、用户与存储用量 |
| 通知公告 | 定向投递（全部 / 角色 / 部门 / 用户）、横幅与弹窗、强制阅读、提醒、阅读统计与接收人；正文用 Markdown 编辑器，HTML 渲染前净化 |
| 我的消息 | 收件箱：已读、全部已读、确认、删除、横幅、弹窗、强制阅读 |
| 消息模板 | 邮件、短信、站内通知、机器人四种渠道；Scriban 变量；租户覆盖平台模板 |
| 邮件短信 | 多通道与缺省通道、租户回落平台；发送记录、取消、重发、删除 |
| 机器人 | 钉钉、飞书、企业微信群机器人；Telegram 机器人（多实例、Webhook 或长轮询、内置命令、出站重试） |
| 在线聊天 | 单聊、群聊（群主与管理员治理）、部门群（随部门归属自动进出）、助手会话（流式回复）；文本、图片、语音、文件，撤回、编辑、表情回应、置顶、服务端转发、提及、已读回执、正在输入；选人可搜索、按部门筛选；附件以会话为访问范围 |
| 聊天审计 | 当前一侧全部会话的消息、消息详情与会话成员；敏感词与保留清理（系统参数 `chat.policy`） |

## 文件与系统管理

| 能力 | 说明 |
| --- | --- |
| 文件管理 | 上传、秒传、分片上传、签名下载与预览（支持 Range）、元数据、归档、副本与主存储、校验 |
| 存储配置 | 本地与 S3 兼容（S3 / OSS / COS / MinIO 经 `ServiceUrl`）、启停、缺省存储；条件写入可按条关掉，给不认 `If-None-Match` 的服务用（见[文件与存储](./backend/file#存储配置)） |
| 导出中心 | 后台以发起人身份逐页调列表操作，CSV / XLSX 存 7 天，到期由作业清理；导入历史 |
| 字典管理 | 字典与树形字典项、缺省项、元数据 |
| 参数配置 | 平台参数 + 租户覆盖、按数据类型校验、加密值不回显 |
| 业务编号 | 前缀、日期、流水位数、重置周期、时区；预览、发号、重置、发号记录 |
| 任务调度 | 代码登记的作业与运行时作业、Cron 构建器与固定间隔、暂停恢复、立即执行、改计划与恢复、失败重试与单次执行时限、运行历史 |
| 缓存管理 | 按应用命名空间与前缀列键（对象缓存与字节存储两层）、查看、修改、删除 |
| 服务监控 | CPU、内存、磁盘、网络、运行时与进程信息 |
| 版本管理 | 平台库与各独立库租户的版本台账、升级记录 |
| 开放平台 | OAuth 2.0 / OIDC 应用与重置密钥、授权同意；个人中心自助管理签名开放接口凭证 |

## 日志与审计

| 能力 | 说明 |
| --- | --- |
| 访问日志 · 异常日志 · 登录日志 | 按月分表、有界队列批量写入；访问日志与开放接口日志可按耗时上下限筛选，异常日志可按发生位置筛选 |
| 操作日志 | 框架操作审计经 `Auditing.Database` 落库；描述取操作的本地化标题，带客户端 IP、浏览器、系统、设备与归属地 |
| 数据变更日志 | 全审计实体的差异日志：新增、修改、删除、恢复；加密参数、AI 密钥、连接串与 Webhook 地址的值打码 |
| 权限变更日志 · 条件命中 · 开放接口日志 | 写入方分别是 Access 与 OpenPlatform |
| 日志链路追踪 | 按 trace-id、用户、登录名、会话、客户端地址聚合成时间线与流向图 |
| 保留清理 | 系统参数 `auditing.retention-days`，作业按 `BasicApp:Auditing:RetentionCron` 执行 |

## 开发与扩展模块

| 能力 | 说明 |
| --- | --- |
| 代码生成 | 数据源、表结构导入与表和列配置、模板维护与预览、生成与生成历史、零代码只读运行时；单表、树表、主从三种模式，生成的后端包与前端模块照当前的包写法；生成到项目只在开发环境且打开 `BasicApp:CodeGeneration:EnableGenerateToProject` 时可用 |
| 流程定义 / 流程实例 | 框架数据库工作流，定义是 `WorkflowJson`；全屏设计器、发布与版本、挂起恢复、取消终止、重试；受理人可按指定用户、发起人、表达式、角色、部门、部门负责人、岗位、发起人第 N 级主管与主管链配置；业务包经审批业务接入 |
| 打印模板 | 平台全局模板与租户模板、按编码解析、数据源经 `AddPrintDataSource` 登记；拖拽设计、样例数据、预览与直打 |
| AI 提供商 / 提示词 / 知识库 / 助手 | 提供商落库（OpenAI 兼容、密钥加密、设缺省、测试连接）；平台与各租户各自维护知识库；助手在聊天里流式回复，按知识库回答，以调用方身份调用勾选的工具 |

## 通用使用体验

| 能力 | 说明 |
| --- | --- |
| 偏好设置 | 亮暗、主题色、布局、密度、水印；偏好与收藏经用户设置跨端同步 |
| 高级列表 | SchemaPage：组合搜索、个人视图、列设置、多列排序、树表、行速览、导出与导入 |
| 内容编辑 | Markdown 编辑器、JSON 查看、Cron 构建器、图标选择器 |
| 全局导航 | 多标签页、收藏、全局搜索、通知中心、分屏、锁屏 |
| 帮助中心与关于页 | 内置「帮助中心」目录（项目概览、官方文档、GitHub、Gitee，种子只首写，之后可改、可停用、可删）；关于页列出项目信息与前后端依赖 |
| 多语言 | 10 种区域，菜单与枚举文案来自后端 |
